## Reality checks from the repo audit

- **No addressable LED is wired anywhere** (`pins.h` has none; zero LED/NeoPixel refs). Every "LED" flourish (Operator Shell, Mayday, Reactor, Keyweave, Firefly, Bloodhound) is unproven — treat as optional until a pin is confirmed.
- **The status bar is ~70% built** — `ui::footer()` already draws the duty%, channel and GPS-fix dot in all 12 apps. The genuinely new bits are small.
- **"Governor" collides** with the existing `DutyGovernor` — rename the power-management feature to **Reactor**.
- **Single-radio physics** caps ADR / high-rate tricks: a LoRa RX only demods the *current* SF/BW/CR, so adaptive rate helps **ACK-gated unicast only**, never broadcast/beacon/mesh.
- **Per-frame auth needs per-node keys.** An 8-byte MAC on the shared channel PSK only proves "sender knows the PSK" (group auth) — SRC spoofing by an insider still works without Keyweave.
- **The 13-byte header has no next-hop field**, so link-state routing needs header surgery or must smuggle next-hop into flags/payload.
- **1% duty is the binding constraint**, and it undercuts the two biggest mesh ideas: Navigator's airtime savings are *shaky* for a mobile mesh (LSA re-floods), and Stream/ARQ's window *collapses toward stop-and-wait*.
- **`DeadReck` (GPS-denied position estimate) does not exist** — several nav/safety features that "fall back" to it must downgrade to last-known-GPS + age (no magnetometer, gyro unused).
- **MGRS is from-scratch geodesy** (~few hundred lines) — not provided by any current lib.
- **Genuinely unused, high-leverage hardware:** ESP32-S3 **WiFi + BLE + USB-CDC**, the **IR transmitter**, the **microphone + ES8311 codec**, and the **BMI270 gyro**. The richest features exploit these.

## Foundational infrastructure (build these first — each unlocks many)

Roughly in dependency order. Several double as catalog features (linked).

1. **Always-on mesh listener / event bus** — one decode path (already exists at `main.cpp onRadioFrame`) feeds badges, toasts, health aggregation and topology; dedup by SRC+MSGID (reuse `relayDedup`). → *Operator Shell*
2. **GPS-UTC disciplined time base** — the RTC-less shared clock; unlocks slotting, wake windows, key rotation, log/nonce freshness. → *Chronos*
3. **Contact Book roster + zeroconf addressing** — durable name↔address foundation used by Courier, Macros, the shell and every label. → *Contact Book*, *Setup Wizard*
4. **Marshal duty-aware TX scheduler / MAC** — the single choke point (CAD listen-before-talk + QoS classes + duty governor) every outbound frame gates through. → *Marshal*
5. **Hardware AES/SHA crypto-services layer** — one wrapper over the S3 engines shared by every security feature.
6. **Trust substrate = Sigil frame-auth + Keyweave key-exchange** — attributable frames + pinned per-node keys that Sentinel, signed time-sync and provisioning key off.
7. **Vault at-rest encrypted storage** — turns the removable microSD into an authenticated encrypted volume. → *Vault*
8. **Host-bridge transport abstraction** — common framing/duty-enforcement beneath every WiFi/BLE/USB-CDC bridge (Gateway, Portal, Halo, Tether, OTA).
9. **Shared radio+SD SPI bus arbiter** — CAD/idle-window scheduling so SD spill never stalls duty-sensitive TX (extends the existing `SpiBus::Guard`).
10. **Navigator link-state routing** — directed unicast + the graph that Multicast/Topology/Tracer consume. → *Navigator*
11. **Stream/ARQ reliable transport (SACK)** — real >200 B delivery for every app. → *Stream/ARQ*
12. **Anti-entropy sync engine (Bloom digest)** — delta-sync substrate under Postbox and Corkboard. → *Sync*
13. **DeadReck estimated-position pipeline** — an `ESTIMATED` quality flag threaded through BEACON so nav keeps working GPS-denied (currently **absent**).

## Catalog by theme

### Operator Experience
- **Status Bar & Duty Meter** — Quick win · S · 5/5/3 — persistent bar with node/chan/GPS/battery/unread + live duty% and *seconds-to-next-permitted-TX*, hold-key help.
  ▸ audit (caveated): footer already shows duty/ch/GPS in all apps — ~70% done. New = node addr + battery + a `DutyGovernor::timeToNextTx()` method (true S). Hold-key overlay needs input-model + shell compositing (→M); defer or make it a `?` screen.
- **Operator Shell (Home + Notifications)** — High-value · M · 5/4/3 — favourites/recents/command-palette home + global toast layer, cross-app unread badges, one-key canned replies.
  ▸ audit (caveated): clean hook at `onRadioFrame` + reuse `relayDedup`; but needs global overlay compositing (`sm.draw` only draws `top()`). LED unverified. Ship badges+toast+palette first; defer favourites/recents.
- **Quick-Send Macros** — High-value · M · 4/5/3 — 1–9 template pad with live `{LAT}{TIME-UTC}{BATT}{BRG:x}{DIST:x}` expansion + airtime-cost preview.
  ▸ audit (caveated): tokens + preview all real & cheap. Drop `{MGRS}` (from-scratch geodesy) or use lat/lon; `{contact}` needs Contact Book; IMU token spurious (no magnetometer).
- **Tap (IMU Gesture UX)** — Quick win · S · 3/4/3 — shake-to-send, tilt-scroll long lists, pocket knock-code to fire a canned alert.
- **SNAP (Screenshot + Flight Recorder)** — High-value · M · 3/4/3 — hotkey framebuffer→SD (scheduled into a radio-idle window) + timestamped RX/TX ring log replayable in Monitor.
- **Chirp (Acoustic Key Handoff)** — High-value · M · 3/3/5 — modulate {channel, key, id} into near-ultrasonic tones decoded via the mic; key never touches RF.

### Spectrum & Medium Access
- **Marshal (MAC/QoS + CAD Listen-Before-Talk)** — High-value · M · 5/4/4 — CAD carrier-sense + backoff + QoS classes (ALERT > TEXT/ACK > control > TELEMETRY > bulk).
  ▸ audit (caveated): CAD exists but is dead code. Real bulk = an async non-blocking TX queue (loop is cooperative; relay re-enters `sendFrame` from RX). "Hidden-terminal collapse" overstated → collision *reduction* among audible neighbours. LBT+AFA is a legit EU868 regulatory alternative.
- **ADR (Per-Neighbour Adaptive Data Rate)** — High-value · M · 5/4/4 — negotiate lowest-airtime SF/BW/CR per destination at a target SNR margin.
  ▸ audit (caveated): single-radio physics → gains confined to **ACK-gated unicast** (Courier DM/Ranger/DROP); broadcast/beacon/mesh get none.
- **TURBO (GFSK High-Rate Bulk Mode)** — High-value · M · 4/3/4 — on a strong link, temporarily switch LoRa→GFSK (~300 kbps) for FILECHUNK/bulk, hard fallback timer.
- **CFO (Carrier-Offset Fingerprint + AFC)** — Quick win · S · 3/4/4 — log per-packet frequency error per SRC: auto frequency correction + a spoof flag when offset leaves a node's learned envelope.
- **GHOST (Stealth Sync-Word / Preamble)** — Quick win · S · 3/5/3 — map channel-id to a non-default sync word so the net is invisible to stock-config receivers.
- **SLOT (GPS-Disciplined Slotted Beaconing)** — Ambitious · L · 4/3/4 — TDMA beacon slots off the GPS UTC second so dense fleets stop colliding.
- **FHOP (Frequency-Hopping Sub-Band Channel)** — Ambitious · L · 4/2/5 — hop the carrier across EU868 sub-bands on a GPS-time PRNG; since duty is *per sub-band*, this legally multiplies usable airtime.

### Mesh Routing & Reliable Transport
- **Tracer (Multi-Hop Traceroute)** — Quick win · S→M · 4/5/3 — each forwarder appends its SRC + heard RSSI/SNR; target returns the hop list with per-hop margin.
  ▸ audit (caveated): edits the shared hot relay path; relay forwards the *still-encrypted* frame, so the record must be cleartext/outside the ChaCha20 body. Dedup(src,msgid) limits loop visibility.
- **Navigator (Link-State Routing)** — Ambitious · L · 5/3/4 — LSAs + Dijkstra + directed unicast instead of flood.
  ▸ audit (caveated): airtime-savings thesis **shaky** under 1% duty for a mobile mesh (LSA re-floods on thrash); reactive/on-demand may fit better. Header has no next-hop field. DST stays cleartext (good).
- **Stream / ARQ (Sliding-Window Transport)** — Ambitious · L · 5/3/3 — numbered fragments + SACK bitmap; reliable payloads past 200 B for every app.
  ▸ audit (caveated): window collapses toward stop-and-wait under 1% duty (SACK spends the receiver's duty). Realistically **unicast/single-hop bulk**, not "over mesh". Core is host-testable in `proto/`.
- **Sync (Anti-Entropy Bloom Gossip)** — High-value · M · 4/3/4 — nodes trade a Bloom digest of held MSGIDs, then send only what the other lacks.
- **Postbox (DTN Store-and-Forward Mailbox)** — High-value · M · 4/3/4 — relay spools a frame for an unreachable DST to SD (CARRY flag), delivers when the node reappears, GPS-UTC expiry.
- **Multicast (Group Addressing Tree)** — High-value · M · 4/3/3 — reserve DST's high bit as a group id; forward only along the union of routes to members.
- **Topology (Live Network Graph)** — High-value · M · 3/4/3 — passively consume LSAs/NODEINFO into a force-directed graph, colour edges by SNR/ETX, flag one-way links & partitions (transmits nothing).

### Fleet Health & Identity
- **Contact Book / Roster** — High-value · M · 5/5/2 — durable name↔address roster from NODEINFO/BEACON, persisted to SD+NVS, with groups/aliases/send-by-name.
  ▸ audit (**solid**): NodeTable is volatile/unpersisted; no roster anywhere. Needs Storage SD-read + a RosterStore + send-by-name wiring. "Block" must also hook the *pre-decrypt* relay path (`main.cpp:70`). v5/f5 holds.
- **Pulse (Piggybacked Health TLV)** — Quick win · S · 4/5/4 — health TLV (battery/uptime/heap/duty-margin/reboot-reason) on the tail of frames already flying, behind a HEALTH flag.
  ▸ audit (caveated): "old parsers ignore it" is FALSE for variable-length TEXT/NODEINFO. Use binary carriers (BEACON/TELEMETRY/PONG), require `FLAG_HEALTH=0x10` (free), strip centrally in `onRadioFrame`. Die-temp is coarse.
- **Setup Wizard + Zeroconf Addressing** — High-value · M · 4/4/3 — first-run identity/channel/key/region/units, MAC-derived address validated by on-air collision listen.
  ▸ audit (caveated): MAC→addr + NODEINFO name directory **already exist** (`main.cpp:128`). New = wizard UI + *best-effort* collision listen + ACLAIM + a units preference (cross-app plumbing is the sneaky cost).
- **Medic (POST Self-Test + Remote Diag Poll)** — High-value · M · 4/4/3 — one-button test of radio/GPS/SD/IMU/PMIC/speaker/IR/mic, packed into a DIAG_REP bitmask for remote fleet triage.
- **Blackbox (Crash Recorder + Watchdog + Safe Mode)** — High-value · M · 4/4/3 — WDT + panic handler capture reason/app/backtrace to an SD ring + RTC-memory breadcrumb; repeated crashes boot a radio-only safe mode.
- **Corkboard (Mesh Bulletin Board / BBS)** — High-value · M · 3/3/4 — leave a GPS-pinned note that epidemically propagates to nodes that later pass by (content-hash + have-digest sync).

### Security & Privacy
- **Sigil (Per-Frame Authentication)** — High-value · M · 5/4/4 — SIGNED flag + authenticator trailer (64B Ed25519 rare / 8B keyed-BLAKE2s chatty); unsigned → "unverified" marker.
  ▸ audit (caveated): 8B MAC on shared PSK = **group auth only** (insiders can still forge SRC); per-SRC needs per-node keys (Keyweave). Ed25519 too heavy for BEACON/ALERT under duty. Relay must verify-before-forward.
- **Keyweave (Authenticated Pairing, LED SAS)** — High-value · M · 4/4/4 — X25519 ECDH + Short-Auth-String confirmed over an LED sequence; per-contact keys via HKDF (IR-SAS variant dropped — no IR receiver).
- **Vault (At-Rest AES-GCM SD Encryption)** — High-value · M · 4/4/3 — wrap SD writes in hardware AES-256-GCM, PIN-derived key, GCM tags catch tamper/bit-rot.
  ▸ audit (caveated): streaming GCM clashes with per-line `appendLine` → needs a per-record AEAD container + nonce counter (no RTC). Threat overstated: keys/profiles live in NVS, not SD; only Breadcrumb CSVs hit the card today.
- **Cerberus (PIN/Duress Lock + Silent Wipe)** — High-value · M · 4/4/4 — boot PIN + shake-to-lock; a duress PIN opens a decoy profile while zeroizing real keys and emitting a hidden distress subcode.
- **Sentinel (Passive RF Intrusion Detection)** — High-value · M · 4/3/4 — sybil/impossible-travel detection, replay rejection (per-SRC MSGID+UTC window), jam detection from CAD-vs-RSSI disagreement.
- **Ratchet (Forward-Secret Message Crypto)** — Ambitious · L · 4/3/4 — symmetric key ratchet for Courier + periodic X25519 DH steps; seizure can't read earlier chats.
- **Cicada (TRNG Entropy Pool + OTP)** — High-value · M · 3/3/4 — whiten mic + IMU + RSSI-LSB + GPS jitter into a TRNG seeding all keys/nonces; optional one-time-pad for crown-jewel messages.
- **Geobox (Geo/Time-Locked Message Keys)** — High-value · M · 3/3/5 — mix the key with a GPS geohash cell and/or a UTC unlock epoch; ciphertext only opens in-area/after-time.
- **Shroud (Rotating Pseudonymous Addresses)** — Ambitious · L · 3/3/5 — ephemeral SRC/CHAN = truncated HMAC(groupKey, UTC/T) so passive loggers see uncorrelatable, reshuffling addresses.
- **Whisper (Steganographic Channel)** — Ambitious · L · 2/2/5 — hide ciphertext inside frames that look like ordinary telemetry on a rotating unlisted channel — metadata-hiding.

### Safety, SAR & Power
- **Mayday (Distress + Dead-Man Switch)** — High-value · M · 5/4/4 — one-key panic (or auto on IMU-stillness + battery-critical) broadcasts a live-position last-will that flips every receiver into a homing screen.

- **Reactor (Battery-Aware Power State Machine + Survival Beacon)** — High-value · M · 5/4/4 — Performance/Balanced/Endurance/Survival profiles auto-degrade CPU/LCD/GPS/radio with hysteresis + a last-gasp findable SAR beacon.

- **Rendezvous (Synchronized Wake Windows)** — Ambitious · L · 4/3/4 — GPS-UTC contact windows: the squad wakes together, drains queued traffic, deep-sleeps — 10–100× less receiver-on time.
- **Firefly (Remote LED Locator + Status LED)** — Quick win · S · 3/5/3 — an IDENT PING strobes a target node's LED to pick it out of a group/dark room; locally colour-codes link quality + silent visual ACKs. *(needs an LED — currently unverified.)*

### Off-Device Connectivity & Time
- **Chronos (Mesh Time Sync + Darkness Planner)** — Quick win · S · 4/5/3 — a time-holding node broadcasts a tiny TIMESYNC so RTC-less nodes get coherent wall-clock; bundles sun/twilight + "darkness in HH:MM".

- **Tether (USB-CDC KISS TNC + JSON API)** — High-value · M · 4/4/4 — expose the radio over native USB-CDC as a KISS TNC (Dire Wolf/aprx) + a line-delimited NDJSON API; sidesteps the cramped keyboard.

  ▸ audit (caveated): WiFi is unused, real, and doesn't contend the SPI bus. RAM tight on no-PSRAM (sync WebServer + tiny HTML); `handleClient()` can stall RX; heavy battery draw → explicit on/off.
- **Gateway / Uplink (WiFi↔MQTT Bridge)** — Ambitious · L · 5/3/5 — mirror the mesh to MQTT/WebSocket (retained NodeTable topics), inject duty-governed downlink, advertise a GWADV route. Interconnects mesh islands over the internet.
- **Xeno (Meshtastic Interop)** — Ambitious · L · 5/3/5 — retune the SX1262 to a Meshtastic preset + AES-CTR PSK and speak its protobufs; two-way interop with the dominant open LoRa-mesh ecosystem.
- **IGate (APRS-IS Uplink/Downlink)** — High-value · M · 3/4/3 — transcode BEACON/TELEMETRY into APRS and push to APRS-IS over WiFi so off-grid trackers appear on aprs.fi.
- **Skylink (LoRaWAN Class-A End-Node)** — Ambitious · L · 3/3/4 — time-share the SX1262 into a LoRaWAN end-node to uplink through any nearby public TTN gateway, no gateway of our own.

# Round 2 — beyond the first backlog

After Round 1's 63 items — and building 8 of them plus the launcher icons — a
second ideation pass ran with **all 63 names as an exclusion set**, focused on
features that **compose the newly-added infrastructure**: the contact **Roster**,
**Marshal**'s TX queue + CAD, the **Pulse** health channel, the **Chronos** time
base, the `App::background()` service hook, and the icon system. 66 ideas → 62
deduped → curated to **52 new** → top 14 feasibility-checked against the current
source (13 confirmed genuinely new; Legend overlaps a deferred Round-1 item).

Scores are **value / feasibility / novelty** (1–5); effort **S/M/L**. **✓** =
feasibility-checked against the source.

## Reality checks from the round-2 audit
- **Muster (R1) should *consume* Presence**, not duplicate its EN-ROUTE state.
- **Fleet overlaps Relay's existing node grid** — build it as a Relay view/columns, not an 18th app. Pulse health is collected but shown nowhere today, so it fills a real gap.
- **Ledger needs a per-app source tag** threaded through `netSend`/`TxQueue::Slot` to the duty charge in `pump()`, with a separate bucket for relay-forwarded frames.
- **`Roster.group` is currently inert** (declared, never read/written) — Roll-Call / Bulletin / Focus need group-assignment UI wired first.
- **Presence/Countdown imply a versioned proto bump** (`HEALTH_LEN` 6→7 or a new codec; `unpackHealth` validates exact length, `PROTO_VERSION`=1) — mind mixed-firmware interop.
- **`heapKb` is transmitted in the Health TLV but dropped by `NodeTable::setHealth`** — Trendline needs a tap to retain it.
- **Signal's "unused speaker" premise is false** — `M5.Speaker` is already used by Klaxon/Mayday; a shared `AudioService` must arbitrate so it can't clobber a live distress alarm.
- **A "background daemon requests foreground" shell hook doesn't exist yet** — Vigil's screen escalation needs it (beep-only works today).
- **Legend ≈ the R1 Status-Bar item's deferred "?-help"** — ship the `?`-screen; "auto-generated, never drifts" needs table-driven key dispatch (a 17-app refactor).
